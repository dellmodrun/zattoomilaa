Dev notes

I wanted a coin whose unit meant something before anyone traded it. Most supplies are a number chosen because it looked round, and the unit is whatever the number divides into. I chose the number of zats in one ZEC because it is a real denomination on a real chain, and because pinning a Solana mint to it makes the mint's unit inherit a meaning it did not earn.

The first decision was that supply only falls. Every mechanism on the site follows from it. Dust is burned rather than carried because carrying it would let the supply hold still. Nullified notes are burned because a round trip that cost nothing would be a loop with no exit.

The second decision was that the program accepts one kind of input and that the input has to come from the other chain. I did not want a button. I wanted the only way to speak to the program to be a shielded transaction with a memo, so that whoever speaks has to spend real zats to do it and still cannot be identified.

The header chain was the price of that decision. If the program is going to act on a memo it has to know the memo exists, and the only way to know without trusting an API is to carry the headers. The witness is anyone. It is slow and it is supposed to be slow.

The site reads from Birdeye every second because the reading has to be alive. It reads fills every fifteen seconds because the quantization tables have to grow while you watch. It reads the Zcash tip every minute because the tip moves every seventy five seconds and reading faster would be waste.

Nothing on the site is a sample. If a value is blank, the input has not arrived. I would rather you see an empty cell than a number I made up, because a made up number on a page about enforcement would be the one thing that disproved the page.

The front page is a preprint abstract because that is the form in which a claim is made and then left alone to be checked. The sidebar reads the market because an abstract about a live object should have the object next to it.

The yellow is the chain's yellow. The ink is the chain's black. There is no third color except the two used to say whether the reading went up or down, and those are the two colors everyone already uses for that.

The profile square is empty on purpose. It is the one place an image would go, and until there is an image worth putting there the square says so by being a square.

The dev panel exists only on the preview. On the published domain there is no way to change the mint and no way to change anything else. The site is a readout, and a readout with a knob is a different kind of object.

I computed the reserve from the fee rate and the fill volume because the program's actual reserve account is not something a site should guess at. The site says what it computed and how. The account says what is true.

If you read this far you have read more about a supply than the supply will ever read about you. That asymmetry is the point.
